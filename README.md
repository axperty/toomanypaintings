### Overview

Too Many Paintings! is a Minecraft mod that adds more paintings from popular artists around the world and a few that I've included myself. The original paintings were taken from [WikiArt](https://www.wikiart.org/en/popular-paintings/alltime) and rescaled to fit with the game's style.

### Contributing

Your contributions allow Too Many Paintings! to be improved to deliver a better gameplay experience for all players. Feel free to submit your code suggestions, bug reports, texture improvements, or translations.

### Features

- Over 60 new paintings.
- Integrates with Minecraft worlds seamlessly, without the need of having to create a new one, and can be uninstalled at any time.
- Works with other mods that also add paintings.
